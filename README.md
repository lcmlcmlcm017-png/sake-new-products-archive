# お酒の新商品アーカイブ

YouTubeチャンネル「sho お酒のメモ」がショート動画で紹介したお酒の新商品を、発売日順に記録する公開アーカイブサイト。GitHub Pagesで公開する。

- 公開URL（Pages有効化後）: https://lcmlcmlcm017-png.github.io/sake-new-products-archive/
- チャンネル: https://www.youtube.com/channel/UCtEkAS8qOJ5roQASHWW9UdA
- 再生リスト「お酒のメモ」: https://www.youtube.com/playlist?list=PLNqKBybgQrIo

## 中身

- `index.html` — アーカイブ本体（単一ファイル、ビルド不要）

## 運用

- 新しい商品のショート動画が公開されたら、Muse が `index.html` への追記分を用意し、承認後にこのリポジトリへ反映する。
- 掲載情報はメーカー公式発表などの一次情報に基づく。価格・発売日は発表時点のもの。
- 個人情報は載せない（公開リポジトリ）。
